HomeKit Notify

Subscribe to push notifications on this device, then paste your unique webhook URL into any HomeKit automation.

Your HomeKit Webhook URL

Use this URL in a HomeKit automation "Run Script" / HTTP action. Optionally append ?title=Hello&body=World to customize the notification.

How to use

  1. Copy the webhook URL above.
  2. Open the Home app → Automations.
  3. Create or edit an automation.
  4. Add a "Run Shortcut" or "Get Contents of URL" action.
  5. Paste the webhook URL as the request URL.
  6. Save — HomeKit will now send you a push notification when the automation fires!
Notifications are delivered via the Web Push API and stored locally on this server.
